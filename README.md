# ペンらくがき

共有メニューで受け取った画像に、拡大しながらペンで書き込み、共有で送り返す Web アプリ（Android の Chrome 向け）。

https://archelon-inc.github.io/pen-rakugaki/

## 入れ方

Android の Chrome で上の URL を開き、メニューの「アプリをインストール」を押す。入れると共有メニューに「ペンらくがき」が出る。

## 使い方

- ペン（S Pen などのタッチペン）で書く。筆圧で太さが変わる
- 指は1本で動かし、2本で拡大する。ペンで書いている間に触れた手のひらは無視する
- ペンのボタンを押しながらなぞると、その間だけ消しゴムになる
- 消しゴムのボタンで消しゴムにし、✒️ で書くのに戻る。書いているときに ✒️ を押すと、ペン・マーカーと色・太さを選べる
- ↶ で元に戻す、⤢ で全体を表示、「送る」で共有メニューを開く
- 書いたものは端末に残り、アプリが落ちても閉じても、開き直せば続きから書ける。新しい画像を開くと入れ替わる

## 確かめ方

Chrome（`google-chrome`）と Node 22 以上で、外から操作して振る舞いを確かめる。

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory .
node test/e2e.mjs http://127.0.0.1:8765/ /tmp/pen-rakugaki-e2e
```
